# navjeetc/tap

Homebrew formulae by [navjeetc](https://github.com/navjeetc).

## aiw

[aiw](https://github.com/navjeetc/aiw): one local full-text search and recap across your AI assistants
(Claude Code, Codex, Claude, ChatGPT, Grok Bot and Muse).

```
brew install navjeetc/tap/aiw
aiw import
aiw recap
```

Homebrew installs the Ruby 3.4 that aiw runs on. You don't need Ruby set up yourself.

Upgrade with `brew upgrade aiw`. A daily workflow opens a pull request here when aiw gets a new release.
