# Navjeetc Tap

## How do I install these formulae?

`brew install navjeetc/tap/<formula>`

Or `brew tap navjeetc/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "navjeetc/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
